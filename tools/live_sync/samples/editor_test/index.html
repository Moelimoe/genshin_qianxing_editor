📖 使用说明

  1. 打开 BeyondAssistEditor
  2. 在物件面板创建对应类型的物件（如金币、酒杯）
  3. 在物件属性中找到「节点图」字段
  4. 导入本目录中的 .gia 文件
  5. 验证节点图是否正确显示
