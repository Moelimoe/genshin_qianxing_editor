# BeyondAssistEditor GIA 测试包

> 本测试包用于验证项目生成的 GIA 文件能否在游戏编辑器中正常加载

## 📦 包内容

- `GIA文件/` - 可导入编辑器测试的 .gia 文件（共 56 个）
- `可视化预览/` - 每个 GIA 对应的 HTML 可视化预览

## 🎯 测试目标

1. **单节点测试**：验证每种节点类型的 GIA 能否正确导入
2. **组合测试**：验证节点连线逻辑是否正确
3. **实体模板测试**：验证完整物件（entity + nodegraph）的 GIA

## 🔧 导入步骤

1. 打开 BeyondAssistEditor
2. 在「物件」面板中找到对应的物件类型（如「金币」「酒杯」）
3. 创建物件实例
4. 在物件属性中找到「节点图」或「Graph」相关字段
5. 点击导入，选择本目录中的 .gia 文件
6. 验证节点图是否正确显示

## ⚠️ 注意事项

1. **type_id 冲突**：部分动作节点（移动实体、播放音效等）的 type_id 可能与编辑器中的真实 ID 冲突，这些节点在编辑器中可能显示为其他类型
2. **ID 冲突列表**：
   - 移动实体 (200002) → 实际是 Logical_OR_Operation
   - 播放音效 (200006) → 实际是 Equal
   - 播放特效 (200005) → 实际是 Enumeration_Match
3. **Client 节点**：部分节点是 Client 专用，可能无法在 Server 节点图中使用
